듀오 브라우저사용자 지원

개인정보처리방침

듀오 브라우저 개발자는 앱의 웹 방문 기록, 검색어, 탭, 북마크, 다운로드를 개발자 서버로 전송하거나 수집하지 않습니다. 앱 자체에는 가입, 광고 SDK, 사용 분석 SDK가 없습니다.

기기에 저장하는 정보

일반 탭의 주소, 북마크, 읽기 목록, 방문 기록, 저장한 읽던 위치, 검색 엔진과 화면 설정이 앱의 기기 저장 공간에 남습니다. 읽던 곳에는 페이지 주소와 제목, 페이지 안의 위치가 저장됩니다. 웹사이트가 설정하는 쿠키와 웹 저장소는 WebKit이 관리합니다. 다운로드를 선택한 파일은 앱의 다운로드 목록에 저장됩니다.

방문 사이트와 검색

페이지를 요청하면 방문 사이트가 접속 IP, 브라우저 정보와 사이트 이용 정보를 처리할 수 있습니다. 주소창에 검색어를 입력하고 실행하면 선택한 검색 서비스에 검색어가 전달됩니다. 각 사이트와 검색 서비스의 처리에는 해당 서비스의 개인정보처리방침이 적용됩니다.

개인정보 보호 탭

개인정보 보호 탭에는 WebKit의 임시 저장소를 사용합니다. 이 탭에서의 방문을 앱의 일반 방문 기록에 추가하지 않으며, 개인정보 보호 탭은 재실행 시 복원하지 않습니다. 웹사이트는 접속 정보를 볼 수 있습니다. 직접 다운로드한 파일, 공유한 링크, 보관함에 추가한 항목은 사용자가 삭제할 때까지 남을 수 있습니다.

보관과 삭제

방문 기록은 보관함의 방문 기록에서 지울 수 있습니다. 북마크, 읽기 목록, 읽던 곳과 다운로드는 각 목록에서 삭제할 수 있습니다. 앱을 기기에서 삭제하면 앱 내부에 남은 로컬 데이터가 제거됩니다. 이미 다른 앱에 저장하거나 공유한 사본은 해당 위치에서 지워야 합니다.
